# Resume Screening Tool (NLP)

An AI-powered resume screening tool that automatically predicts the **job category** of a resume using Natural Language Processing (NLP) and Machine Learning. Upload a resume in **PDF, DOCX, or TXT** format and get its predicted job category instantly through a simple web app.

## Problem Statement

Recruiters receive **thousands of resumes** for every job opening. Manually reading each resume and sorting it into the right job category (Data Science, HR, Java Developer, Sales, etc.) is:

- **Slow** — screening one resume takes minutes; thousands take weeks
- **Error-prone** — human fatigue leads to mis-categorization and missed candidates
- **Biased** — different recruiters screen the same resume differently

**Goal:** Automate the *first stage of the hiring pipeline* — upload a resume, and let an ML model instantly classify it into the correct job category so recruiters only review the relevant pile.

## Features

- 📄 Upload resumes in **PDF, DOCX, or TXT** format
- 🔍 Automatic text extraction + cleaning (removes URLs, hashtags, mentions, punctuation, non-ASCII noise)
- 🤖 ML-based category prediction across **25 job categories**
- ⚡ Instant prediction through a clean **Streamlit** web interface
- 💾 Trained model, TF-IDF vectorizer, and label encoder saved as reusable pickle files

## How It Works

1. **Dataset** — 962 resumes labeled across 25 job categories (Data Science, HR, Java Developer, Sales, DevOps Engineer, …).
2. **Class balancing** — Categories are oversampled to 84 samples each (the largest class size) so the model doesn't ignore smaller categories.
3. **Text cleaning** — URLs, `http` links, hashtags (`#...`), mentions (`@...`), punctuation, and non-ASCII characters are stripped from resume text.
4. **TF-IDF vectorization** — Cleaned text is converted to numerical features with `TfidfVectorizer(stop_words='english')`. Words that are distinctive for a category get higher weight.
5. **Train / test split** — 80% train, 20% test (`random_state=42`).
6. **Model comparison** — Three classifiers trained with `OneVsRestClassifier`:
   - KNeighborsClassifier → **99.76%** accuracy
   - **SVC (final pick) → 100%** accuracy
   - RandomForestClassifier → **100%** accuracy
7. **Persistence** — The SVC model, TF-IDF vectorizer, and label encoder are saved with `pickle`.
8. **Inference (app.py)** — The Streamlit app loads the pickles, extracts text from the uploaded file, cleans it, vectorizes it, and predicts the category.

## Installation & Usage

```bash

pip install streamlit scikit-learn python-docx pypdf pandas numpy

# 2. Train the model (generates clf.pkl, tfidf.pkl, encoder.pkl)
#    Run: Resume_Screening_with_Python.ipynb

# 3. Start the web app
streamlit run app.py
```

Then open the browser link shown in the terminal, upload a resume (PDF/DOCX/TXT), and see the predicted category.

## Limitations & Future Scope

- Accuracy is measured on a tutorial-scale dataset with fairly distinct categories; real-world resumes (career switchers, hybrid roles) are messier and would need more data and calibration.
- Currently predicts **one** category per resume — could extend to multi-label or confidence scores ("Data Science: 82%, Analyst: 15%").
- Next steps: add resume–job-description **matching/ranking**, explainable predictions (highlight the keywords that drove the category), and a REST API for ATS integration.
